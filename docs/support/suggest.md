# Suggest an improvement

Ideas are welcome — especially the small ones that would save you a minute every shift.

[:material-lightbulb-on: Suggest an improvement](https://github.com/thegippygeek/carersportal-docs/issues/new?template=enhancement.yml){ .md-button .md-button--primary }

Tell us the problem you are trying to solve, not just the feature you imagine; there is often a simpler way to get you there. Same rule as bug reports: no participant details.
